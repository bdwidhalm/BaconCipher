# BaconCipher

Android application for encrypting and decrypting Bacon Ciphers.  


## Background
A bacon cipher is a method of steganographic message encoding devised by Francis Bacon in 1605.  
See [Bacon Cipher](https://en.wikipedia.org/wiki/Bacon's_cipher)
